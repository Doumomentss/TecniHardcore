# Ruleta 3D de TecniHardcore

La ruleta aparece como una rueda holográfica de diez sectores lisos de colores sobre la plaza. Gira durante siete segundos, desacelera y produce un destello al detenerse. No hay títulos ni texto dentro de la rueda; el giro usa posición y tiempo enviados por el servidor para que los clientes actualizados vean la misma animación.

Comandos de operador nivel 4:

- `/tecni ruleta preview`: reproduce la animación para los conectados y no cambia reglas.
- `/tecni ruleta activar`: reproduce el giro y activa el paquete de dificultad únicamente cuando termina.
- `/tecni ruleta estado`: muestra si el paquete está inactivo, girando o activo.

El resultado real se conserva tras reiniciar el servidor. La rueda 3D requiere el cliente TecniHardcore 2.9.13 o posterior; los clientes anteriores reciben el mensaje de actualizar.
